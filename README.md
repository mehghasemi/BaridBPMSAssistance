# فرم‌یار

برای اجرای برنامه در ویندوز، روی فایل `Start-Formyar.cmd` دوبار کلیک کنید.

اسکریپت در صورت نیاز، وابستگی‌ها را نصب می‌کند، دیتابیس SQLite محلی و داده نمونه را آماده می‌کند و سپس برنامه را در مرورگر پیش‌فرض باز می‌کند.

نیازمندی سیستم: Node.js نسخه LTS.

## انتقال به یک سیستم دیگر

فایل `Formyar-Portable-20260916.zip` را منتقل و Extract کنید. سپس فقط روی
`Start-Formyar.cmd` دوبار کلیک کنید. این اجراکننده فایل `.env` را در صورت نیاز
از `.env.example` ایجاد می‌کند، وابستگی‌ها را نصب می‌کند و دیتابیس محلی را آماده
می‌کند. اتصال اینترنت در اجرای اول برای دریافت بسته‌های npm لازم است.

برای اجرای دستی نیز می‌توانید از دستور زیر استفاده کنید:

```powershell
npm run dev
```
