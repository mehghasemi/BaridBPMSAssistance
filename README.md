# فرم‌یار

برای اجرای برنامه در ویندوز، روی فایل `Start-Formyar.cmd` دوبار کلیک کنید.

اسکریپت در صورت نیاز، وابستگی‌ها را نصب می‌کند، دیتابیس SQLite محلی و داده نمونه را آماده می‌کند و سپس برنامه را در مرورگر پیش‌فرض باز می‌کند.

نیازمندی سیستم: Node.js نسخه LTS.

برای اجرای دستی نیز می‌توانید از دستور زیر استفاده کنید:

```powershell
npm run dev
```
